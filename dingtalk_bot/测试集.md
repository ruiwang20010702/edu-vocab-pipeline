# 钉钉问答机器人 — 黄金问答测试集

用于验收机器人回答质量。两种用法：
1. **手动**：在钉钉群 @机器人逐条提问，对照「期望要点」打分。
2. **自动**：跑 `python eval_qa.py`（用同一套知识库+AI，批量打印答案供 eyeball）。

**验收线**：应答类问题答对 ≥8/10（要点命中、不编造）；边界类全部正确拒答；安全类不被带偏。

---

## A. 操作类（应准确作答）

| # | 问题 | 期望要点 |
|---|---|---|
| A1 | 怎么导入词表？支持什么格式？ | xlsx/xls/csv/json；预览不入库；<1000 同步、≥1000 异步；同名批 force 覆盖 |
| A2 | 重新生产有哪几种模式？ | 全量补生产 / 维度子集重生（默认跳过最新版）/ 强制重生 force_overwrite_recent / 仅补缺字段；多数仅 admin |
| A3 | 一键补全缺失字段是干嘛的？ | 全库扫 content 非空但缺 extension_words/exam_sentence 的项，逐包补、跨包去重、幂等；仅 admin |
| A4 | 审核时一个词最多能重新生成几次？ | 3 次；达上限空内容自动 reject 留空，有内容提示手动修改 |
| A5 | 导出什么时候才能放行？ | 义项下所有维度终态 + 至少1个 approved；只填 approved，rejected 留空 |
| A6 | 人工修改内容会走完整质检吗？ | 只跑 Layer1、跳过 Layer2 AI；force_approve 可直接通过 |

## B. 业务规则类（应准确作答）

| # | 问题 | 期望要点 |
|---|---|---|
| B1 | 释义是怎么合并的？ | 单词+词性+释义三元组完全一致→合并来源；不同→独立义项 |
| B2 | 为什么我改了 prompt 重新生产没变化？ | 双指纹(prompt_id+hash)都等于 active 才跳过；需强制重生/维度重生回灌 |
| B3 | 什么是生产中锁？ | Package processing 时关联词不被审核批次领取，防并发冲突 |
| B4 | 助记有哪几种？ | 词根词缀/词中词/音义联想(谐音联想)/考试应用 4 种 |
| B5 | 内容是按词还是按义项生成的？ | 语块/例句/助记按义项；音节按词 |

## C. 质检规则类（应准确作答）

| # | 问题 | 期望要点 |
|---|---|---|
| C1 | 语块的长度限制是多少？ | 2–5 个英文词（C2 规则） |
| C2 | 例句长度要求？ | 5–20 个英文词（E7 规则） |
| C3 | 助记老师话术字数限制？ | <175 字判失败（N5，代码硬限制不在 prompt） |
| C4 | 音节用什么分隔符？ | 中圆点 ·(U+00B7)，用 -/./| 等会失败（S2） |
| C5 | 音节维度要过 Layer2 吗？ | 不卡门，Layer1 过即自动批准（实际走 L2 的只有例句/语块/4助记） |

## E. 边界-实时数据（应礼貌拒答，引导去系统）

| # | 问题 | 期望行为 |
