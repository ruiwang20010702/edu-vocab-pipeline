# 内容维度与核心业务规则

## 五个内容维度

| 维度 | 按词/义项 | 怎么来 |
|---|---|---|
| 音标 + 音节(syllable) | **按词** | 音标(英/美式 IPA + 发音URL)由**导入**写入、不参与重生；音节由 AI 按音节拆词、用中点 `·` 分隔 |
| 释义(meaning) | 定义义项 | **由导入产生**，不由 AI 生成、不参与重生；导入时规范 POS、把半角标点转全角 |
| 语块(chunk) | **按义项** | AI 生成，返回英文+中文翻译 |
| 例句(sentence) | **按义项** | AI 生成，返回英文+中文翻译 |
| 助记(mnemonic) | **按义项** | AI 生成，4 个变体；统一返回 `{valid, formula 公式, chant 口诀, script 老师话术}` |

> 内容按义项挂载是为了防止多义词张冠李戴；音节是词级所以按词。

### 助记 4 个变体

| 变体 | 维度名 | 含义 | 额外字段 |
|---|---|---|---|
| 词根词缀 | `mnemonic_root_affix` | 用词根+词缀拆解；复合词/无合法派生词缀的词须 valid:false | `extension_words`(同根词) |
| 词中词 | `mnemonic_word_in_word` | 在大词里找认识的小词；基础不可拆词须 valid:false | — |
| 音义联想(导出标签"谐音联想") | `mnemonic_sound_meaning` | 谐音/象声联想；牵强或语义负面须 valid:false | — |
| 考试应用 | `mnemonic_exam_app` | 围绕固定搭配/介词/考点；无高频考点须 valid:false | `exam_sentence` + `exam_sentence_translation` |

> AI 判该词不适用某助记法时返回 `valid:false`；只有严格 True 才算有效，其余（含字符串 "false"）一律按无效（fail-safe）。

## 核心业务规则

1. **释义合并**：导入按 `(单词, 词性, 释义)` 三元组精确匹配——完全一致→只追加来源不新建义项；释义或词性不同→保留为独立义项。来源去重还看 教材/词书/单元 ID。
2. **内容按义项挂载**：chunk/sentence/4 助记按义项；syllable 按词。
3. **Prompt 版本指纹去重**：每条内容记 `prompt_id + prompt_hash`。重生时**两者都**等于当前 active prompt 才算"已最新"被跳过。老数据（prompt_id 为空）或 active prompt 无 hash → 不跳过、强制重生。
4. **仅补缺字段模式**：忽略指纹，只命中"content 非空但缺主 extra 键(如 extension_words/exam_sentence)"的项，用于回填代码修复后的旧数据，不动已正确项、不重判 valid:false 词。
5. **生产中锁**：Package 为 processing 时其关联词被排除、不进新审核批次，防生产/审核并发冲突。
6. **导出门禁**：义项可导出 = 其下所有维度都处终态(approved 或 rejected) 且至少 1 个 approved；词还要求 syllable 处终态。只填 approved 内容，rejected 维度留空。
7. **重新生成上限 3 次**：用原子计数防并发超限。三种决议：approved / regenerate / manual_edit。人工修改只跑 Layer1 跳过 Layer2。助记可"标记不适用"（清空+rejected+记指纹）。
8. **空内容达上限自动 reject**：重试达上限时——内容为空(AI 反复做不出)→自动 reject 留空、提示"已标记为不适用(留空)"；有内容(质检反复不过)→不自动处理，提示"请手动修改"。

## 质量门禁状态机

`pending → layer1_passed/failed → layer2_passed/failed → approved`，或 `rejected`。失败态只能回 pending 重生。
- 生成失败(空 content)标 `layer1_failed` 让质检接管；AI 判 valid:false 直接 rejected。
- 自动批准：layer2_passed → approved；layer1_passed 且该维度无 L2 规则(如 syllable) → approved。
