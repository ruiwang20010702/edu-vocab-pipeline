# 常见问题 FAQ

**Q：某个词的某维度为什么是空的 / 导出后有留空？**
A：被拒（reject）或未通过审核的维度会留空，这是 fail-safe 设计的正常表现，不是 bug。只有 approved 的内容才会被填进导出。

**Q：一个词被拒了怎么办？**
A：可以对该维度重新生产（最多 3 次）。若反复不过，需检查 prompt 或源数据；空内容达重生上限会自动 reject 留空。

**Q：我改了 prompt，为什么重新生产没变化？**
A：系统用 prompt 版本指纹去重——指纹和当前 active prompt 一致会被当成最新版跳过。改 prompt 要先部署同步、让 active 指纹变化；若改的是生成器代码（非 prompt），普通重生会被跳过，要用"一键补全 / 仅补缺字段"回灌。

**Q：音标格式有要求吗？**
A：内部存储为剑桥风格（点分音节、英式/美式分列）。残缺音标（以 `-` 开头的相对音标）和缺失音标需在源表补全，系统不会自动兜底。

**Q：词性可以随便填吗？**
A：不行，必须用 23 个权威带点标签之一（见"质检规则与 POS 标签"）。导入器只规范格式不校验合法性，非法词性要在源表改。

**Q：为什么我的批次领不到某些词 / 词在生产中？**
A：Package 状态为 processing 时，其关联词被锁，不会被新批次领取，避免生产与审核并发冲突。等生产结束即可。

**Q：导出什么时候能放行？**
A：一个义项的所有内容项都到终态、且至少 1 项 approved，才允许导出。
