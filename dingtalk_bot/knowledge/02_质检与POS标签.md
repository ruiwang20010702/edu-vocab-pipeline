# 质检规则与 POS 标签

## 质检整体流程

两层串行，Layer 1 通过才进 Layer 2，任一层不过即进人工审核队列：

1. **Layer 1（算法规则）**：捞所有非终态内容项，按维度匹配规则，全过→`layer1_passed`，任一失败→`layer1_failed` 进审核队列。
2. **Layer 2（AI 语义校验）**：**仅对 layer1_passed 的项执行**（硬门禁，L1 没过根本不送 AI）。全过→`layer2_passed`，失败/AI 异常/超时→`layer2_failed` 进审核队列（不会静默放行）。
3. **人工审核** → approved / rejected（最多 3 次重生）。
4. **导出门禁**：只有 layer2_passed 且审核 approved 才进最终产出。

机制要点：
- **维度通配**：`dimension=mnemonic` 的规则自动匹配全部 `mnemonic_*` 子维度；`phonetic` 规则只匹配 phonetic。
- **AI 未配置时 Layer 2 整体放行**（占位模式 passed=True）。
- AI 调用失败/超时不放行，标 `layer2_failed` 进队列（审核员会看到 AI 失败类条目，需人工补判）。

## Layer 1 算法规则（按维度，共 25 条）

**音标 phonetic**
- P1 IPA 格式：英式/美式全缺、未用 `/ /` 包裹、含非法 IPA 字符 → 失败。
- P2 音标-音节对齐：音节按 `·` 分隔的块数 ≠ 音标块数 → 失败。

**释义 meaning**
- M3 词性合法：缺 pos、或 pos 不在合法标签集 → 失败。
- M4 词性换行：同一行出现 >1 个词性标签 → 失败。
- M5 义项分号：含中文逗号但无分号且逗号拆出≥2段 → 失败（疑似多义项误用逗号）。
- M6 禁括号：释义含任意括号 → 失败。

**语块 chunk**
- C1 含目标词：语块不含目标词原形或常见词形变化 → 失败。
- C2 长度：英文词数 <2 或 >5 → 失败（合法 2–5 词）。
- C4 禁括号。
- C6 中文翻译 <2 字 → 失败。
- C5 无独立中文字段时英文块混入中文 → 失败。

**例句 sentence**
- E6 含目标词（同 C1 词形规则）。
- E7 长度：英文词数 <5 或 >20 → 失败（合法 5–20 词）。
- E8 中文翻译非空且含中文字符。

**音节 syllable**（校验生产切分出的 content，用 `·` 分隔）
- S1 元音锚点：每块需含元音（词尾 -le 成节辅音例外）。
- S2 分隔符：必须用中圆点 `·`(U+00B7)，用 `-`/`.`/`|` 等错误分隔符 → 失败。
- S3 原子单位完整：辅音二合字母/元音组合/r 控元音不可跨音节拆开。
- S4 单音节不切分：单音节词被切成多块 → 失败。

**助记 mnemonic**（content 必须是含 formula/chant/script 的 JSON，适用全部助记子维度）
- N1 JSON 格式 + 必备键完整。
- N2 formula/chant/script 任一为空 → 失败。
- N3 公式 formula 须含 `+`、`≈`、`=` 之一。
- N4 口诀 chant 字数：>15 字失败；**考试应用类放宽到 30 字**。
- N5 老师话术 script：4 种助记类型统一 **<175 字判失败（无上限）**。（注：字数硬限制在此 N5 代码规则，不在 prompt）
- N6 实战例句（**仅考试应用**）：exam_sentence 为空/含中文/词数不在 8–15/不含目标词 → 失败。
- N7 实战例句中文翻译（**仅考试应用**）：该字段存在时为空或不含中文 → 失败；旧数据缺该字段直接通过（不回打已通过内容）。

> 逻辑字数：连续英文字母算 1 字、每个中文字算 1 字，标点/空格/数字不计。

## Layer 2 AI 语义校验（各维度判什么）

> **音节例外（重要）**：代码里虽定义了音节 L2 规则(SA1–SA7)，但生产/重生编排**不把音节纳入 L2 门禁**——音节 **Layer 1 通过即自动批准**，不被 L2 卡。实际走 L2 门禁的只有：例句、语块、4 个助记维度。

- **音节(SA1–SA7，仅在显式跑 L2 时生效)**：单/多音节准确性、元音锚点、原子单位保护、静音字母、辅音切分位置、前缀完整、分隔符。
- **例句(E1–E11)**：语法在初中大纲内、以简单句为主、连接词仅 and/but/so/because、定语从句限制、无非谓语/虚拟/倒装等禁区、中英语义对应、目标词用法对应义项（防张冠李戴）、地道无中式英语、内容阳光中性。
- **语块(C3)**：是否英语高频固定搭配（而非随意组合）。
- **助记(N5_AI、N6)**：话术是否含完整步骤框架且逻辑通顺、拆解是否合理（防"伪助记"牵强拆解）。

> 重要：默认 UNIFIED 模式下 **释义(meaning) 维度没有 Layer 2 AI 校验**（词义-词性匹配 M7 只在非默认的 PER_RULE 模式生效）。释义日常只过 Layer 1 的 M3–M6。
